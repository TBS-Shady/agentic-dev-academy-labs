# Agentic Dev Academy: hands-on labs

Free hands-on labs for the **GH-600 Agentic AI Developer** certification exam. They go with the Agentic Dev Academy study course: the course explains each topic, and these labs let you practise it in a real repository.

> Independent study material. Not affiliated with or endorsed by GitHub or Microsoft, and contains no real exam questions.

## Getting started

1. Start with **Lab 0: Set up your lab**. It creates `agent-lab`, a small practice repo that every lab uses.
2. Work through the labs in order. There are four per exam domain, and later labs reuse files from earlier ones.

You'll need a paid GitHub Copilot plan, VS Code with Copilot Chat, Copilot CLI, the GitHub CLI, Node.js 20+ and Git.

## What's in this repo

| Folder | Contents |
| --- | --- |
| `labs/` | One page per lab, grouped by exam domain |
| `labs/companion/` | Optional open-source Python agent labs (MIT licence, by Ed Donner) for background |
| `docs/decisions/` | Short records of design choices |

The lab pages are published from the course source, so please report problems as an issue rather than opening a pull request against a lab page.
